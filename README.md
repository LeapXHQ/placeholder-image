# placeholder-image

Public repository hosting logo and placeholder images for the LeapX app.

**Caution: This is a public repository. Do not commit any sensitive or internal assets here.**

## Image URLs

Images are served via GitHub raw URLs:

```
https://raw.githubusercontent.com/LeapXHQ/placeholder-image/main/<path>
```

Example: `https://raw.githubusercontent.com/LeapXHQ/placeholder-image/main/harmony-logos/logo-harmony.png`
